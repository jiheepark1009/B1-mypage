About Me

숫자 너머의 이야기를 찾는 데이터 분석가

축구와 야구를 좋아하다 보니, 경기 기록 한 줄에도 선수의 컨디션과 팀의 전략이 담겨 있다는 걸 알게 됐습니다. 이 관심은 자연스럽게 “그 데이터를 어떻게 분석하고, 어떻게 의사결정에 쓰이게 만들까”라는 질문으로 이어졌습니다.

현재는 스포츠 경기 데이터 분석과 스포츠 마케팅 데이터 분석, 두 축을 중심으로 프로젝트를 진행하며 데이터 분석가로서의 실무 역량을 쌓고 있습니다. 숫자를 예쁘게 그리는 것보다, 그 숫자가 전달하는 “다음 행동”을 제안하는 분석을 지향합니다.

  • 축구(EPL·K리그)·야구(KBO) 경기 데이터 분석 경험
  • 마케팅 캠페인 성과 데이터 기반 전략 제안 경험
  • Python·SQL 기반 데이터 수집·전처리 파이프라인 구축
